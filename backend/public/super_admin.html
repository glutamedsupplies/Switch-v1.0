            How to add a specification

            Pick a category, click Add specification, type its name (for example "Sugar Level") and an optional example value, then click Save. Sellers see the new list the next time they open Add Listing.

            Categories you have not edited use the starting list in backend/config/productSpecifications.js, or the default list if the category is not there. Reset to code list removes your edits for that category.

            Renaming a specification keeps the values sellers already entered. Removing one drops it from listings the next time they are edited.
